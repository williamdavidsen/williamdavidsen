## 🚀 Bachelor project

### API-based Security Assessment Platform for SMB Customers

For my bachelor project, I am working on a security assessment platform designed for small and medium-sized businesses.

The project combines a **C# / ASP.NET Core backend** with a **React + TypeScript dashboard**. A user enters a domain name, and the system performs several automated security checks before presenting the results in a structured and understandable dashboard.

The platform includes checks for:

* SSL/TLS configuration
* HTTP security headers
* Email security records such as SPF, DKIM and DMARC
* Domain reputation data
* Post-quantum cryptography readiness indicators
* Combined scoring, status, warnings and module-level results
